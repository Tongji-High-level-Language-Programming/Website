# 答疑

本课程的问题交流分为两条渠道，请先分清它们各自负责什么：

| 渠道 | 用途 |
| --- | --- |
| [同济高程答疑平台](http://10.80.42.185/QA/) | **课程答疑**。课程相关问题的提问、讨论与解答都在平台各仓库的 Issue 区进行 |
| 课程 QQ 群 | **通知与文件分发**。课程通知、开学大礼包等文件通过 QQ 群发布 |

::: tip

遇到课程相关的问题，请一律到答疑平台上提问。QQ 群只用于接收通知、获取文件，群内不进行答疑。

:::

## 我该从哪里看起

- 第一次提问：先读 [提问指南](/qa/ask/)，学会如何描述问题、提供必要的信息。
- 还没登录过平台：看 [答疑平台使用指南](/qa/gitea/)，了解登录、搜索 Issue、提问与回复的完整流程。
- 遇到了具体的报错：先查 [常见问题解答](/qa/faq/)，许多问题已有现成的答案。
