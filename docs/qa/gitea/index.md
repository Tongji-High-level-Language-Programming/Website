# 高程答疑平台使用指南

## 平台与访问条件

课程的答疑主要在 [同济高程答疑平台](http://10.80.42.185/QA/) 上各个仓库的 Issue 区进行。网站仅限同济大学校园网或同济 VPN 访问。

课程 QQ 群不用于答疑，仅用于发布课程通知与分发文件；其余渠道（如私聊助教）也不作为答疑渠道，请在平台上提问，以便问题与解答能被保留和检索。

## 组织结构

平台上的内容按多层结构组织：

+ **组织（Organization）**：按年份划分，对应每一届课程。由管理员组织划分。
+ **仓库（Repository）**：暂时没有划分规则
+ **Issue**：每个具体的问题都以 Issue 的形式存在。

::: tip
Issue 是本平台的“核心提问单元”，它相当于一条带有标题、内容、评论和状态的讨论帖子。每个具体问题都会以一个 Issue 的形式被创建，提问者可以在其中描述遇到的问题、附上代码、截图、报错信息等；其他同学和助教可以在下面继续回复、补充说明和给出解决方案。Issue 还支持标签分类，因此大家可以按主题、模块或状态快速筛选和查找问题。与一般的聊天软件不同，Issue 会被保留在平台中，方便后续搜索、复盘和追踪解决过程。
:::

![从仓库进入到 Issue 列表界面](RepoToIssue.png)

*理论上组织下可以包含多个仓库，每个仓库中又可以包含多个 Issue。* 

## 搜索已有的 Issue

首先需要进入对应的仓库页面。

![同济高程答疑平台仓库页面](DashboardRepo.png)

提问之前，先在仓库的 Issue 列表中搜索是否已有相同或相似的问题。

![仓库 Issue 搜索](SearchIssue.png)

如果你找到了相似的 Issue，点击对应 Issue 进入即可查看相关解答。

![Issue 搜索结果](SearchIssueResult.png)

如果没有找到相关 Issue，可以参考下一节，选择发布一个新的 Issue。

## 发布新 Issue

::: warning
发布 Issue 前，请再次确认你的问题符合 [提问指南](/qa/ask/) 中的规范。并且，提出已经存在的相同或相似的问题很有可能被判定为**重复 Issue**，将很有可能被关闭，**不会**得到回答。
:::

当你需要开一个新的 Issue 时，点击`创建 Issue`的按钮。

![创建新 Issue](CreateIssue.png)

进入之后自行判断选择合适的分类（以仓库实际情况为准，若没有则跳过这条）。

![Issue 模板分类](IssueFilter.png)

进入之后根据已有的模板填写尽量详细的信息。

![填写 Issue 模板](FillIssueTemplate.png)

信息填写完成之后点击页面最下方的 `创建 Issue` 按钮。

![创建 Issue 按钮](CreateIssueButton.png)

这样你的 Issue 就成功创建了，其他同学和助教可以在该 Issue 下进行提问和回复。

## 评论回复

当你需要在已有的 Issue 中继续提问或回复时，可以在该 Issue 页面底部的评论框中输入你的内容，然后点击 `评论` 按钮。

![Issue 评论](IssueComment.png)

然后你就可以等待其他同学或助教的回复。

## 关闭/重新打开 Issue

::: warning
有权限关闭/重新打开 Issue 的用户仅包括提问者和具有相应权限的助教/老师。
:::

当这个 Issue 提出的问题得到解决后，建议你选择关闭该 Issue。关闭 Issue 的操作通常由提问者完成，表示问题已经得到满意的解答。

在 Issue 页面底部的评论框下方，找到 `关闭 Issue` 按钮，点击即可关闭该 Issue。

![关闭 Issue 按钮](CloseIssue.png)

当然，如果你的 Issue 重复或者完全无意义/不符合规范，它可能会被助教/老师直接关闭。~~比如问今天吃什么。~~

当你觉得你的 Issue 未得到解决却被关闭，你可以选择重新打开这个 Issue。同样在 Issue 页面底部的评论框下方，找到 `重新打开` 按钮，点击即可重新打开该 Issue。

![重新打开 Issue 按钮](ReopenIssue.png)

## 为什么 Gitea 作为答疑平台？

> [Gitea 是什么？](https://docs.gitea.com/zh-cn/)  
> [Git 是什么？](https://git-scm.com/book/zh/v2/%E8%B5%B7%E6%AD%A5-%E5%85%B3%E4%BA%8E%E7%89%88%E6%9C%AC%E6%8E%A7%E5%88%B6)  
> [Github 是什么？](https://baike.baidu.com/item/github/10145341)  

如你所见，Gitea 提供了完整的基础的 Issue 管理功能，便于课程中问题的答疑和追踪。

当然，目前只使用其 Issue 功能，其他功能的利用正在规划中。

相比群聊，使用 Issue 答疑的好处是：

+ 可以用 Issue 模板规范化提问，确保提供必要的信息
+ 问题与回答被完整保留，不会因为群消息刷屏而丢失
+ 可以方便地追踪问题的解决进度
+ 其他同学遇到相同问题时可以搜索到已有的解答，避免重复提问/解答浪费时间
+ 按知识模块分类管理，便于针对性地查找
+ 可以挑选出有价值的问题，供所有人方便地参考
