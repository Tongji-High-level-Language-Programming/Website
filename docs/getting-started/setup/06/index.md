# 安装 Chrome 浏览器

本课程的部分文档作业是在线完成的，题目设置时只匹配了 Chrome 浏览器，如果完成作业过程中碰到有显示不完整等情况，建议安装 Chrome 浏览器。

## 使用大礼包中的安装包

大礼包中给出了安装包，可以直接使用：

- **安装包名**：`ChromeSetup.exe`
- **安装包大小**：`10,752,440` 字节
- **SHA256 校验码**：`afcfb481b61d23534e393e1bb75413c28b21dfebcf5f2e1bb2169fa5176d5b2f`

## 自行下载

也可以自行下载 Chrome 浏览器的其他安装包（注意分辨是否广告）。

::: tip

Chrome 浏览器官方提供免费下载，请认准官方渠道，不要使用需要付费的“下载站”。

:::

::: tip

只要网页显示完整、操作正常，也可以不安装 Chrome。

:::

具体安装过程不再赘述。
