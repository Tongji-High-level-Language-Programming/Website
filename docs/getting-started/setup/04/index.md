# 小熊猫 C++ 的安装与配置

::: details 目录

[[toc]]

:::

## 安装步骤（共 8 步）

### 1. 找到安装文件

从 QQ 群开学大礼包中获取**小熊猫 C++**的安装文件

![安装文件](001-找到安装文件.png)

### 2. 运行安装程序

鼠标双击 `小熊猫C++ 3.4.3279 with gcc-15.2.0 同济定制版.msi`，按“下一步”继续。

![运行安装程序](002-运行安装程序.png)

### 3. 确认安装文件夹

> [!IMPORTANT]
> 一定要严格按照操作步骤执行！

![确认安装文件夹](003-确认安装文件夹.png)

### 4. 开始安装

![开始安装](004-开始安装.png)

### 5. 等待安装完成

什么也不做，等待安装完成。

![等待安装完成](005-等待安装完成.png)

### 6. 完成安装

按“完成”结束安装，桌面会出现对应图标。

![完成安装](006-完成安装.png)

### 7. 启动小熊猫 C++

双击桌面上的“小熊猫 C++”图标，或从开始菜单中选择“小熊猫 C++ 3.4.3279”项启动。启动成功则表示安装过程完成。

![启动](007-启动.png)

### 8. 检查默认选项

::: tip

本课程整个学期的**所有作业**均要求这些配置项，因此建议定期检查。

:::

#### 8-1：打开“选项”对话框

在“工具”菜单中选择“选项”。

![打开选项对话框](008-打开选项.png)

#### 8-2：编译器配置 - 基本选项检查

![基本选项检查](009-基本选项.png)

#### 8-3：编译器配置 - 编译/链接选项 - 代码生成检查

![代码生成检查](010-代码生成.png)

#### 8-4：编译器配置 - 编译/链接选项 - 代码警告检查

![代码警告检查](011-代码警告.png)

#### 8-5：编辑器 - 杂项 - 文件编码检查

![文件编码检查](012-文件编码.png)

至此，小熊猫 C++ 安装、配置完成，可以使用。
