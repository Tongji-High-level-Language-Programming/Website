# Windows 系统配置修改

::: tip

1. 首先在电脑上安装“QQ·Windows 版”。
2. 本次及后续所发的所有文档，都是在电脑上打开。
3. 本次及后续所发的所有安装，都是在电脑上进行。
4. 不回答手机打开文档后所发生的一切问题。
5. 只能是 Windows 电脑，Mac/Linux/鸿蒙等非 Windows 系统无技术支持。
    - 后期作业会用到一些 Windows 特性的东西。
    - 作业提交后用基于 Intel/AMD 的 Windows 进行正确性测试，如果用 Mac 版 Visual Studio/虚拟机/Wine 等方式测试并提交作业，需**自行确保代码正确**；出现兼容性问题会判错并扣分，这种情况**不支持申诉**，分数损失由提交者自行承担。

## 1. 调整文件夹选项

::: warning

第一步非常重要，不要漏做！

:::

### 1-1：打开控制面板

鼠标右键点击任务栏“开始”图标，选择“运行”，在出现的“运行”对话框中输入“control”：

![运行](002-运行.png)

![输入control](003-打开控制面板.png)

### 1-2：在“控制面板”中选择“外观和个性化”  

![外观和个性化](004-外观和个性化.png)

### 1-3：选择“文件资源管理器选项”  

![文件资源管理器选项](005-文件资源管理器选项.png)

### 1-4：调整设置

出现的对话框中，选择“查看”卡片，让下图中的五项与截图图示一致，按“确定”  

![调整选项](006-调整设置.png)

## 2. 关闭智能应用控制

::: warning

第二步非常重要，不要漏做！

:::

点击 [此链接](windowsdefender://smartapp/) 或通过 `设置-隐私和安全性-Windows安全中心-应用和浏览器控制-智能应用控制设置` 打开设置页面，将其设为“关闭”。

### 2-1：打开“Windows 安全中心”

打开 Windows“设置”，左侧选择“隐私和安全性”，右侧选择“Windows 安全中心”。

![打开 Windows 安全中心](032-智能应用控制1.png)

### 2-2：进入“应用和浏览器控制”

在“Windows 安全中心”中，右侧选择“应用和浏览器控制”。

![进入应用和浏览器控制](033-智能应用控制2.png)

### 2-3：进入“智能应用控制设置”

右侧选择“智能应用控制设置”。

![进入智能应用控制设置](034-智能应用控制3.png)

### 2-4：关闭“智能应用控制”

如果右侧显示“打开”或“评估”，则改为“关闭”。

![关闭智能应用控制](035-智能应用控制4.png)

::: tip

旧版 Windows 系统中可能没有“智能应用控制”，此时忽略这一步即可。

:::

## 3. 关闭“使用 Unicode UTF-8 提供全球语言支持”

::: warning

第三步非常重要，不要漏做！

:::

### 3-1：打开“语言和区域”设置

打开 Windows“设置”，左侧选择“时间和语言”，右侧选择“语言和区域”。

![打开语言和区域](036-打开语言和区域.png)

### 3-2：展开“Windows 显示语言”

点击“Windows 显示语言”右侧的下三角（∨）。

![展开 Windows 显示语言](037-展开显示语言.png)

### 3-3：关闭 Beta 版 UTF-8 选项

将“Beta 版:使用 Unicode UTF-8 提供全球语言支持”设置为“关闭”。

![关闭 Beta 版 UTF-8](038-关闭UTF8.png)

::: tip

- 该设置会影响 Windows 处理中文编码的方式。如果后续仍遇到中文乱码问题，可参见 [常见问题解答：中文乱码](/qa/faq/#中文乱码)。
- **Windows 显示语言** 与 **“非 Unicode 程序的语言”** 也均需设置为**中文**。

:::

::: details 找不到上述选项？旧版 Windows 的设置方法

#### 旧版 Windows 的区域和语言设置 {#old-windows-region}

本课程所有提交的代码文件均要求使用国标字符编码（GB2312/GBK/GB18030，不区分这三者的细节）。大部分情况下，VS 创建空项目后默认即为符合要求的编码。

在 Windows 10 或旧版 Windows 11 中，可能找不到上文“Beta 版:使用 Unicode UTF-8 提供全球语言支持”的开关；此时，如果出现“程序运行时中文显示为乱码”等问题，可以按下列步骤检查设置：


1. 右键点击开始菜单，选择“设置”，打开 Windows 设置面板

   ![设置面板](039-区域设置1.png)

2. 选择左侧“时间和语言”，在二级菜单中打开“语言和区域”

   ![语言和区域](040-区域设置2.png)

3. 选择“管理语言设置”

   ![管理语言设置](041-区域设置3.png)

4. 选择“管理”选项卡，打开“更改系统区域设置”

   ![更改系统区域设置](042-区域设置4.png)

5. 确保区域设置项为“中文（中国）”，且“Beta 版：使用 Unicode UTF-8 提供全球语言支持”**未被选中**

   ![区域设置](043-区域设置5.png)

6. 重启计算机，观察问题是否得到解决

:::
